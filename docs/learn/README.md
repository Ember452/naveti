# 学习文档（learn）

替想读懂这个项目的读者写的材料：既收**本项目自己写的入门与讲解**，也收**有出处的外部资料**（译文、转载）。这里的内容不是权威——同一个事实以 `docs/` 根下的权威文档为准；本文与它们冲突时，以它们为准，并回来修这里。

## 条目命名

`YYYY-MM-DD-<主题>.md`，日期是**进入本仓库的日子**，不是原文发布日（原文发布日写在篇内出处块里）。前缀的作用是让"什么时候拿来的"可查，而不是排序优先级——这里的阅读顺序由下面那张表说。

## 外部资料的规矩

1. 篇首必须有出处块：原文链接、作者、原文发布日期、翻译或转载声明。
2. 只放全文与逐段译注，不放"译文 + 我的发挥"混排——自己的判断写进 `.agents/notes/` 或本仓库自己的讲解文里，两者混在一篇会让读者无法区分谁的说法。
3. 外部资料描述的是**它写作时的上游**，不是本仓库现状。本仓库改过内核的部分以 `docs/kernel/divergence.md` 为准。
